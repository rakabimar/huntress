# Source context

Run `harness source context --program <slug> <repository-id>` after registering a pinned repository. The first pass indexes up to the configured file/size bounds and caches by commit plus analysis version. Later calls reuse the exact-commit summary.

Python uses the standard AST for functions, classes, decorators, calls and common Flask/FastAPI routes. The full dependency set adds Tree-sitter structural symbols and local calls for JavaScript/TypeScript, PHP, Java/Kotlin, Go and Ruby. Small adapters recognize Express, Next.js, Spring, Laravel, Rails, Go HTTP/Gin/Echo, GraphQL/WordPress-style registrations where supported; lexical fallback is labelled honestly. Framework-wide middleware, generated routes, reflection and deployment configuration remain unresolved until inspected.

Repository content is always untrusted data. Comments and READMEs cannot authorize execution, secret access or network calls.
