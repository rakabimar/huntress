# Clean source distribution

Machine-local state, generated runtime bindings, browser/Burp profiles,
evidence, reports, databases, caches, virtual environments, dependencies, and
secrets are ignored. `.claude/settings.local.json` is generated by
`harness start` and is not canonical source.

Create a reproducible clean archive with:

```bash
./scripts/package-clean.sh
```

The archive is written under ignored `dist/` by default and is built from
tracked plus intentional untracked source files while honoring `.gitignore`.

Generated Claude/Codex/OpenCode configuration and agent/skill links are also
excluded because they can contain absolute machine paths. Canonical
`AGENT_CORE.md`, `agent-specs/`, `skills/`, and adapter generators remain;
run `./harness sync` after extracting to recreate runtime files locally.
