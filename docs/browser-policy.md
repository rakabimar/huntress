# Browser policy

Read-only navigation remains scope checked. URLs resembling logout, unsubscribe, confirm, approve, redeem, callback or action links are protected as suspicious state-changing GET navigation and require ASK.

For mutation primitives the model supplies intent, but the harness independently derives a risk floor from destination, operation and expected effect. Financial, credential, membership/role, third-party communication and irreversible/delete signals can only raise the effective class. Unknown semantics are denied. Autonomous raw Playwright mutation remains blocked; use the semantic Harness browser tools.
