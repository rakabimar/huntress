# SQL differential methodology

Classify input as value, identifier, operator/fragment, or second-order data. Capture a stable baseline and select the cheapest applicable proof: paired boolean/content differential, controlled semantic/error pair, or short repeated timing trio with jitter controls. Keep request shape equivalent and change one expression.

Attribute the result to query structure through repeatability and negative controls. Stop at the smallest proof; never enumerate schema/data, use writes/stacking/file functions, or deploy long/heavy timing payloads.
