# Authorization evidence contract

Link: object creation/ownership evidence; authorized baseline; unauthorized same-object operation; AuthContext IDs/roles and tenant/relationship; exact method/path/version/fields; protected response fields or authoritative before/after state; intended-behavior source; and one refuting-control comparison.

For nested resources include both parent and child ownership. For batch/search/export/jobs include each input ID, filtering semantics, artifact/job owner, and retrieval result. Do not persist reusable credentials, unnecessary foreign data, or an enumeration set.
